# rimworld-adventure

「环世界冒险」八模组 Steam 创意工坊页面的描述配图，共 34 张。

这些图只用于嵌入 Steam 工坊页的 **描述正文**（工坊自带的图片展示区放不了描述内嵌图）。

## 目录说明

| 前缀 | 用途 | 数量 |
|---|---|---|
| header- | 每个模组页的页头横幅（1280×270） | 8 |
| sec- | 通用章节牌匾（1280×200，八页共用） | 5 |
| items- | 物品一览图（1280 宽） | 9 |
| mech- | 机制详解图（1280 宽） | 9 |
| cover- | 合集封面（cover-collection 大图 / cover-collection-s 小图） | 2 |
| 合计 | 全部配图 | 34 |

## 直链用法

全部文件平铺在根目录，所以可以用一个基址引用：

    https://cdn.jsdelivr.net/gh/ATOIN/rimworld-adventure@main/<文件名>.png

或 GitHub 原样：

    https://raw.githubusercontent.com/ATOIN/rimworld-adventure/main/<文件名>.png

模组：一以贯之（Core）、天工开物、源源不绝、列国春秋、切磋琢磨、石药尔雅、钟鸣鼎食、披坚执锐。
